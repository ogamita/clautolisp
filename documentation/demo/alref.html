Demonstration alref

alref defini quelques fonctions pour obtenir la documentation des fonctions et variables (system variables) d'autocad et de bricscad.

On charge le source alref.lsp, puis on défini la racine de la documentation autolisp-spec. Ceci peut être fait avec cette fonction load-alref: 

(defun load-alref ( / root)
  (load "/opt/local/share/autolisp/site-lisp/autolisp-spec/alref.lsp")
  (setq root "/opt/local/share/autolisp-spec/")
  (if *AUTOLISP-VERBOSE*
      (progn
        (princ "alref root set to ")
        (princ root)
        (princ "\n")))
  (alref-set-root root)
  'load-alref)
